# Calculator ROM Collection

## 개요
CHIP-8 32비트 확장 플랫폼을 위한 계산기 ROM 컬렉션입니다. 스택 프레임 오퍼레이션, syscall, I/O 기능을 활용한 3가지 버전의 계산기를 제공합니다.

- **기능**: 123 + 456 = 579 고정 계산
- **스택 프레임**: PUSH RBP, MOV RBP RSP, SUB RSP 사용
- **함수 호출**: CALL_FUNC/RET_FUNC로 함수 간 호출
- **I/O**: WRITE syscall로 결과 출력
- **용도**: 스택 프레임 동작 확인 및 기본 테스트

**메모리 레이아웃:**
```

0x1100: add_numbers() - 덧셈 함수  
0x1200: print_result() - 출력 함수

```
